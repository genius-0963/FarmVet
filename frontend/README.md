# FarmVet Frontend

This is a simple React frontend for the FarmVet backend.

## Install

```
cd frontend
npm install
```

## Run

```
npm start
```

The app runs locally at `http://localhost:3000` and calls the backend at `http://localhost:8082`.

## Backend

Start the backend from the project root:

```
cd ..
.\mvnw.cmd spring-boot:run
```
